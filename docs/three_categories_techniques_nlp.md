# Three Categories of NLP Techniques

NLP techniques can be broadly grouped into three main categories:

## 1. Rule-Based Techniques

These techniques use predefined rules and patterns to process text.

**Example:**

* Regular Expressions (Regex)
* Extracting phone numbers, emails, dates, or order numbers
* Text cleaning

Rule-based methods are useful when the patterns are well-defined.

---

## 2. Machine Learning

Machine Learning algorithms learn patterns from data instead of relying only on predefined rules.

**Example:**

* Text classification
* Spam detection
* Sentiment analysis
* Document classification

Common algorithms include:

* Naive Bayes
* Logistic Regression
* Support Vector Machines (SVM)

---

## 3. Deep Learning

Deep Learning uses neural networks to learn complex patterns and representations from large amounts of text.

**Example:**

* BERT
* Transformers
* Large Language Models (LLMs)
* Text generation
* Question answering

Deep Learning is especially powerful for understanding context and relationships between words.
